# B45: check-devices runs lemnos-ctl validate on every board file

**Group:** B. Board descriptions

**Needs:** B20, B18

Lemnos ships `lemnos-ctl validate [--socs DIR] [--no-live] BOARD`: it checks a board file and shows the host settings
it gives, with no daemon. check-devices runs Gaia's validate and plan, not Lemnos's. On 2026-11-22 two board-file faults
showed only on Raze #2: the PIO I2C bus's jumps (Lemnos ea434b1e) and cam0-sensor's address shown as "unknown".

## Build

- `scripts/check-devices.sh` runs the locked Lemnos's `lemnos-ctl validate --no-live --socs <the lock's socs>` on every
  `devices/boards/*/lemnos-board.toml`. The binary is built from the products' Lemnos lock, with the same rule as Gaia's
  binary: another commit, none, or -dirty is refused.
- A refusal names the board file and Lemnos's own words.
- `.pending.toml` board files are validated too; their failures are reported as notes.

## Proof

A bad board file (self-test case) is refused in Lemnos's words; every committed board file passes, or its failure is
recorded with an owner.
