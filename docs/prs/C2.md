## Build

- Every device gets a Hardware tab in the app, built only from what the board describes: Lemnos's device list, each device's description, values with units, health with reasons, and the board file's identity facts. No code per kind of device and nothing hard-coded for a product. If a description lacks something the tab needs (a human name, a unit, a grouping), say so in the PR text: Lemnos adds it to the description. Never fill a gap from a table in Atlas.
- Built on `atlas-session` (`crates/board/session`), the one connection to a node. It works for any Orion node; what needs a board identity says so.
- Live readings, hardware description and logs as Orion topics, with no code for any kind of device: Atlas shows what the board describes.
