# Z2: the ZERO 3E bench image as a U-Boot slot image

Status: DRAFT. Pins unmerged Lemnos pr/BB1b (e2e45ce7) and Gaia pr/rk-env (1db105c). Untested on board.

## What changed
- `devices/products/zero-3e-bench`: recipe `slot-boot` (the raze-base pattern), `initramfs = ["lemnos-slot-init"]`,
  Lemnos components as this product's own copies pinned at Lemnos pr/BB1b e2e45ce7 (the shared components stay at
  f4a295c6 for the Raze), and a board component `zero-3e-slot-board` (Lemnos `tree`, `boot-partition`, `bundle`; the
  BENCH key). Access stays: USB gadget (serial-hash-v1 lemnos0), Ethernet DHCP and mDNS, hostname from serial, PC key,
  watchdog, serial console. The Z1 `kernel/` directory is removed; its pieces moved to the board and the family.
- `devices/boards/radxa-zero-3e/lemnos-board.toml`: the slot form (record `uboot`, SD as U-Boot mmc 1,
  `uboot_env_size = 0x10000`, watchdog `/watchdog@fe600000`, bays). Source: Lemnos `testing/boards/rk3566-slots.toml`
  at e2e45ce7. The fastboot pair 1209:0001 is the pid.codes TEST pair, not a registered id.
- `devices/families/rk35xx/assets/u-boot.fragment`: HARD RULE lines `CONFIG_ENV_MMC_USE_DT=y`,
  `CONFIG_ENV_MMC_DEVICE_INDEX=1`, env size 0x10000 (as Gaia rk-env 1db105c sets them), plus the boot-path options
  Lemnos's `--uboot-config` names (`service/ctl/src/boot_dir.rs`, e2e45ce7). Lemnos's generator does not write
  USE_DT; Atlas adds it.
- `devices/families/rk35xx/assets/linux.fragment`: `CONFIG_PSTORE`, `CONFIG_PSTORE_RAM`, `CONFIG_PSTORE_CONSOLE` =y
  (Lemnos BB3).
- `devices/boards/radxa-zero-3e/assets/dts/rockchip/rk3566-radxa-zero-3e-ramoops.dtsi`: the ramoops node (0x110000,
  0xf0000; console 0x20000, record 0x10000), included by the gadget DT.
- `scripts/check-devices.sh`: `rk_env_rule` refuses a slot-recipe product on an rk35xx board whose U-Boot config lacks
  `CONFIG_ENV_MMC_USE_DT=y` or `CONFIG_ENV_MMC_DEVICE_INDEX=1`, or whose family lacks the 16M/128K uboot-env partition.
  `rk_env_self_test` removes each line from a scratch copy and requires the refusal to name it.

## Open / untested
- Board partitions: the board file still has only the family's raw areas. Gaia's slot-boot planned without a boot or
  data partition in the board, so the disk layout for the slot image is Gaia's to confirm at the real build.
- `boot_size` = 134217728 (128 MiB) and the bays (kernel 32 MiB raw, initramfs 1 MiB, dtb 256 KiB, overlay 16 KiB,
  cmdline 4 KiB) are Atlas's estimates. Gaia's `boot-report` gives the real figures; a too-small bay is refused by name.
- Kernel: PSTORE lines and ramoops are not yet proven by a kernel build (`scripts/check-kernel-fragments.sh` not run).
- Gate: not run. The Cargo pin rule fails it (STOP 1). No Rust changed.
- Reflash: the maskrom path is Lemnos's worker (not in this PR).
- Nothing booted. Nothing flashed. No board access.
