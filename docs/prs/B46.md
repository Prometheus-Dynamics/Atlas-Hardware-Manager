# B46: build-product.sh --build-mode and --medium

**Group:** B. Board descriptions

**Needs:** B22

Gaia 129e07e7 and later key steps on two argument tokens: `@build@` ("clean", or "dev-reuse" under `--dev-reuse`) and
`@medium@` (the board's `[flash] medium`). These keys change a step only when an argument names them.
`scripts/build-product.sh` passes neither, so every Atlas build is a clean build for the board's default medium. The
Atlas side was parked on 2026-11-18, until Lemnos's flag and Gaia's binding landed (the `build.mode` marker in
`slots/<id>.json`).

## Build

- `scripts/build-product.sh <product> [--build-mode clean|dev-reuse] [--medium <name>]`, passed through to Gaia.
- `clean` is the default and the only mode for a release.
- A `dev-reuse` build is marked as one in its slot (`build.mode`), and `atlas-next` refuses it on a board that is not a
  bench board.
- `--medium` is refused unless the board file lists that medium.
- State which Gaia and Lemnos revs carry the binding. Until both are on the lock, the flags are refused with that reason.

## Proof

The flags reach Gaia (the plan shows the keyed step changed); a dev-reuse slot carries its marker; an unknown medium is
refused.
