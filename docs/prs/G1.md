## Build

- Every job in the design's first rule, with real clicks, on a Raze over USB and the network: flash blank, update, each slot operation, trial fallback, readings, logs, files, backup, terminal, recovery.

## Checks this run must make

- lemnosd starts as root and drops to its own user: record the running daemon's uid and gid, its capability set (only CAP_SYS_RAWIO), and that the USB gadget and the fan's PWM still work after the drop. This run is the first time that drop is exercised on a board.

- The gadget on a real controller under systemd's sandbox: Lemnos has proven it only in QEMU on a dummy controller. On the board: the FunctionFS mount succeeds (from the Lemnos rev after 554319df this needs the `gadget.conf` drop-in, installed exactly when the board file has a gadget), the host sees the five interfaces, the NCM addresses and USB serial equal the derived values, and bulk data passes both ways.

- VBUS in device mode (from Lemnos Q2f at 96080d36, docs/prs/B21.md, "The meter check"): a meter on the device port's VBUS. 0 V with the cable unplugged; plugged into a host, the board adds no 5 V to the host's line. Record both readings with the board's `vbus_reason`.
