## Gadget drop-in (Lemnos R1d)

The base `lemnosd.service` no longer has the gadget's `ReadWritePaths`. The drop-in
`packaging/systemd/lemnosd.service.d/gadget.conf` adds the FunctionFS mount's `CAP_SYS_ADMIN`, the
`mount umount2` filter entries and the configfs path. It is installed to
`/etc/systemd/system/lemnosd.service.d/gadget.conf` only by a component whose installed board file
(`/etc/lemnos/board.toml`) has a `usb-gadget` device. `scripts/check-lemnos-gadget.py` reads both
facts from the data and fails both ways; its `--self-test` checks four fixtures. Today the only
installed board is the Raze's, and it has the gadget, so the drop-in is installed there.
