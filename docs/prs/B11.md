## Build

- A dev-only bring-up product per board: it boots from an SD card, brings up the network over USB device mode and over Ethernet, and gives SSH with the bench key, which is a Gaia build input and is never committed. No Lemnos and no Orion. It proves the loader, the kernel and the device tree before the managed image goes on.
- It is the one place a dev-only unit is allowed, and the product says so. The base products stay as they are.
