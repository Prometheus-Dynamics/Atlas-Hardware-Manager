## Build

- Every family except the Pi starts the flasher image through U-Boot's USB fastboot: the boot ROM loader gets U-Boot running from RAM (Rockchip: 471 DDR init, then 472 with U-Boot as the payload; Allwinner: FEL loads the SPL, then U-Boot; K230: the same if its boot ROM allows it), then `atlas-fastboot` downloads and boots the flasher kernel and initramfs. The Pi's boot files start the flasher directly.
- One flow for every family: the loader starts the flasher image; the board appears as an Orion node on the USB link; the first-flash image is an ordinary update. The same flow recovers a broken board. Runs detached, so it survives the app closing.

## Proof

Test with a simulated loader and the simulated node; board runs in G1 and G3.
