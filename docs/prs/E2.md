## Build

- Atlas finds a controller and offers to install its package (B8: Orion and Lemnos as one `.ipk`), using the controller's own package install. It shows what is installed and its version, updates it, and removes it. After the install the controller is an ordinary Orion node; nothing temporary is set up to talk through it.
- dev's USB agent and its HTTP port do not come over.
