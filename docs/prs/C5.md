## Build

- Install, set default, trial boot, guarded remove, keep-last-N, per-update keep and per-slot pin, as Orion actions on the Lemnos update drivers (X1). Atlas makes the slot bundle from the `.img.xz` on the computer. One writer, no A/B.
- Until X1 lands, build against the action names in Lemnos's I5 brief on the simulated node and mark the real board run open.

## Proof

Tests against the simulated node: every slot operation; a trial that is not confirmed falls back; removing the previous slot is allowed and clean.
