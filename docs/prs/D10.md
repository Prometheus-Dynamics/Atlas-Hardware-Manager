## Build

- A small fastboot client over `atlas-usb`: `getvar`, `download` and `boot` only. No flash, erase or OEM commands.
- Every family except the Pi starts its flasher image the same way: the boot ROM loader gets U-Boot running from RAM, then U-Boot's USB fastboot takes the flasher kernel and initramfs into RAM and boots them. This crate is that last step.
- The device re-enumerates when U-Boot starts and again when the kernel boots; both are expected, not errors.

## Proof

Tests against a simulated fastboot device: download and boot, a refused download, a stall, a disconnect at boot counted as success.
