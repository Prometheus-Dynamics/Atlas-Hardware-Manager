## Build

- The first-flash `.img.xz` is the only build output, and Atlas makes the slot bundle from it. This is the reader behind `atlas-bundle`'s source seam: streamed xz, the partition table first, then the boot partition and the data partition in order (a stream can't seek).
- Read-only ext4 with the `ext4-view` crate at the version Gaia `next` pins; the boot partition with `fatfs` or a small reader of our own. Bounded memory. The image is untrusted input.
- Both image forms: Gaia's bring-up form (`rootfs` and `data` partitions, the slot file on `data`) and the real form (a boot partition with per-slot kernel, DTB and initramfs, and `slots/<id>` on data).
