## Build

- For every family except the Pi the flasher product also builds a U-Boot with USB fastboot enabled: the boot ROM loader starts that U-Boot from RAM, and fastboot takes the kernel and the initramfs.
- One product per family: an initramfs with the Orion recovery build and the storage drivers, loaded into memory by the boot ROM loader. No flasher daemon and no flasher protocol: once it runs, the board is an Orion node on the USB link. LEDs show progress.
