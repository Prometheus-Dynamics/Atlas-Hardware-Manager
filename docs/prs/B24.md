## Referencing the component from our products

Gaia at `4509f6b` takes a product's `[components]` only as a relative path to a `component.toml` in the same tree,
so Gaia's own example (`examples/components/usb-gadget-network`) cannot be named from our product directories.
A component may install a file from a git source (`from = { source = "...", path = "..." }`), which is a form
Gaia supports. So:

- `devices/components/usb-gadget-network/component.toml` declares `[sources.gaia]` (the Gaia repo at the pin) and
  two `[[install]]` entries that take Gaia's `files/S41usb0` and `files/udhcpd.usb0.conf` from that source. It
  carries no copy of those files.
- Our one own file is `files/usb-gadget-network.service`, the systemd unit that runs the script. Gaia's
  component is a SysV init script (`S41usb0`) and the images are systemd, so the script would never run without it.
  The unit is `[Type=oneshot, RemainAfterExit, ExecStart=/etc/init.d/S41usb0 start, Restart=on-failure, RestartSec=5,
  StartLimitIntervalSec=0]`. Gaia's `[[services]]` takes only a unit name, so the unit file is installed by us.
- The product lock records the source at the pin (`usb-gadget-network.gaia`, `commit = 4509f6b...`).

## Address cross-check (ZERO 3E)

Family `radxa-zero-3e`, serial `b3d1ffecafae5cec` (read on the board: `/proc/device-tree/serial-number`, INPUTS.md).

- The component's own rule (run with `sh S41usb0 addresses radxa-zero-3e b3d1ffecafae5cec`, the script's `addresses`
  subcommand, no system effect): **`62:3a:62:a8:c9:a6 62:3a:62:a8:c9:a7`**.
- An independent Python computation (`python3 -I`, a scratch script, `hashlib`):
  input bytes `radxa-zero-3e:b3d1ffecafae5cec`, SHA-256 of `lemnos-usb-ncm\0` + input is
  `613a62a8c9a731a5b0e7c091dfd4db93e91e47dadbd4c623eed953226cebd1a4`; first 6 bytes `61 3a 62 a8 c9 a7`, first octet
  `(0x61 & 0xfc) | 0x02 = 0x62`; host `62:3a:62:a8:c9:a6`, device `62:3a:62:a8:c9:a7`.
- Lemnos's `drivers/usb-gadget/src/derive.rs` (origin/next) states the same rule and vectors; Gaia's test vector
  (`alpha`, `00000001`: host `b2:b5:ba:4c:1e:30`) matches the Python computation.

**Result: the same two addresses** (`62:3a:62:a8:c9:a6` host, `62:3a:62:a8:c9:a7` device). Nothing to resolve.
