## Build

- A link kind for a local disk, and the disk driver's manifest using it, so the registry calls it.
- `atlas-usb`'s device summary carries `bcdUSB` (and the device release number), so a Rockchip maskrom device can be told from one running the loader. The Rockchip driver uses it.
- The catalog gains: port maps, more than one picture, lens variants of one board, the case orientation fields (`case_in_imu`, `ring_led0_deg`, `ring_direction`), vendor-wide USB ids, and a way to name a device recognised without USB (a robot device).
- The inventory keeps a copy of a file written by a newer Atlas before rewriting it.
- `atlas-release` signs and verifies raw bytes, and `atlas-bundle` uses it in place of its own ed25519 calls.
