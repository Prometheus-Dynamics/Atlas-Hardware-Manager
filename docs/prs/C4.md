## Build

- Built on `atlas-session` (`crates/board/session`), the one connection to a node. It works for any Orion node; what needs a board identity says so.
- Sending an image or any file to a board with Orion's file delivery, resumable, with progress; fetching a support bundle. No image server.

## Proof

Test: a 1 GB file to the simulated node over a throttled link, interrupted and resumed.
