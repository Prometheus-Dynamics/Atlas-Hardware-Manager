## Build

- This PR adds `"apps/*/src-tauri"` to the root `Cargo.toml` workspace members (the one allowed edit of that file here): cargo refuses a member glob that matches nothing, so it could not be listed before the app existed.
- Tauri and the UI skeleton: opens at once with the last known inventory, every command async, state from events. `scripts/ui-gate.sh` builds the UI, checks that every command is async, and runs the click tests.
