## Build

- dev never built an image for these boards, so nothing is carried over: this is a new choice. Research and pin a candidate kernel and U-Boot (most likely the vendor BSP for the A733), by commit, marked unverified and never booted.
- The user's standing goal is the latest 7.x kernel where the chip can run it. The board files record the kernel version chosen and what blocks moving to mainline 7.x, as an open item.
- A dev-only bring-up product as for the other boards.
