How to read these

All names, numbers and sizes are sample data for layout.
Light or dark follows your system setting. Every colour is a token in atlas.css.
Tabs on the board page are plain radio buttons: click Logs, Files or Terminal.
Every screen fits 1024×680, 1320×860 and 1830×1030 with no page scroll.
