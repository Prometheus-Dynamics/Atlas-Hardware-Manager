PLACEHOLDER, NOT AN OVERLAY. Not compiled, not listed in board.toml [kernel] overlays.

The Raze's one new overlay (the camera path for Lemnos). Its source comes from Lemnos docs/device-tree.md
(Lemnos Q2), which is not on Lemnos origin/next as of this PR (checked at 0d54a5ef). Until it lands,
this file says what the overlay must do, and nothing else:

  1. enable rp1_csi0 (csi@110000) with NO sensor node and NO endpoint, so the receiver is up for Lemnos;
  2. enable the camera I2C adapter, i2c-10 (i2c_csi_dsi0), with its pins;
  3. enable rp1_pio;
  4. disable cam0_reg (the fixed regulator on RP1 GPIO34 that powers the sensor's line).

The camera path is PROVISIONAL until Q2 lands: the sensor entry in raze-lemnos-board/files/board.toml
is disabled for the same reason.
